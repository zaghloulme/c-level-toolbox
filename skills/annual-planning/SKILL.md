# Annual Strategic Planning

## Core Principle

AN ANNUAL PLAN IS NOT A WISH LIST — IT IS A RESOURCE ALLOCATION DOCUMENT THAT FORCES YOU TO SAY NO TO GOOD IDEAS SO YOU CAN SAY YES TO THE BEST ONES.

## Phase 1: Reflect

Review the past year before planning the next one.

### Required Inputs

| Input | What to Ask | Default |
|-------|------------|---------|
| **Last year's performance** | "What were the key financial and operational results?" | No default — must be provided |
| **Last year's wins** | "What were the top 3 accomplishments?" | No default |
| **Last year's misses** | "What was planned but not delivered?" | No default |
| **Biggest lesson** | "What is the one thing the organization learned this year?" | No default |
| **Current team** | "What does the leadership structure look like?" | No default — must be provided |
| **Available budget** | "What is the approved budget for growth and strategic initiatives?" | No default — must be provided |

### Year in Review Template

```
## [Previous Year] in Review

**Revenue:** [Amount] ([+/-X%] vs. prior year)
**Top 3 Wins:**
1. [Win + measurable impact]
2. [Win + measurable impact]
3. [Win + measurable impact]

**Top 3 Misses:**
1. [What was planned + why it didn't happen]
2. [What was planned + why it didn't happen]
3. [What was planned + why it didn't happen]

**Key Lesson:** [One sentence]

**What to keep doing:** [Activities that drove results]
**What to stop doing:** [Activities that consumed resources without return]
**What to start doing:** [New priorities for next year]
```

**GATE: Complete the review before setting new goals.**

## Phase 2: Set Goals

Define the annual strategic direction and break it into goals.

### Annual Theme

Every year gets a single theme — one word or phrase that guides decisions when priorities conflict:

```
**[Year] Theme:** [e.g., "Profitability," "Market Expansion," "Operational Foundation," "Client Depth"]
```

### Goal Framework

Set 3-5 annual goals using this structure:

```
## [Year] Goals

### Goal 1: [Specific, Measurable Outcome]
**Metric:** [How success is measured]
**Target:** [Number or milestone]
**Why it matters:** [Connection to organizational strategy]
**Resources needed:** [Budget, headcount, time]

### Goal 2: [Specific, Measurable Outcome]
...
```

### Goal Quality Check

Every goal must pass these tests:
- **Specific:** Can it be explained in one sentence?
- **Measurable:** Is there a number or clear milestone?
- **Achievable:** Are the resources available to pursue it?
- **Relevant:** Does it connect to the annual theme?
- **Time-bound:** Does it have a deadline within the year?

**GATE: Confirm annual goals before cascading into quarters.**

## Phase 4: Execution System

Set up the review rhythm that keeps the plan active throughout the year.

### Review Cadence

```
## Planning Review Rhythm

**Weekly (15 min):** Review actions against monthly targets
**Monthly (30 min):** Review progress against quarterly milestones
**Quarterly (2 hours):** Full review — adjust goals, reallocate resources
**Annually (half day):** Full year review and next year planning
```

### Quarterly Review Template

```

**Goal progress:**
```

## Anti-Patterns

- **Too many goals** — more than 5 annual goals means nothing gets the focus it needs. Prioritize ruthlessly.
- **No quarterly milestones** — annual goals without quarterly checkpoints drift until Q4 panic.
- **Planning without reviewing** — skipping the prior-year review means repeating the same mistakes.
- **No resource allocation** — goals without budget and headcount attached are not plans.
- **Set it and forget it** — the plan is a live document. Quarterly reviews keep it relevant.

## Recovery

- **Organization has never done formal annual planning:** Start with 2-3 goals and quarterly milestones. Add structure in subsequent cycles.
- **Last year had no clear goals:** Use revenue, customer count, and gross margin as proxy metrics for the review.
- **Goals set too aggressively:** Apply the 50% test — if the team delivers 50% of an aggressive plan, is that still a strong year? If yes, keep the stretch. If not, recalibrate.
- **Mid-year and no plan exists:** Run the same process with a 6-month horizon. A mid-year plan is better than none.
- **Leadership team cannot align on priorities:** Use the resource allocation exercise to force trade-offs. Conflicts that surface in planning are cheaper to resolve than conflicts during execution.
